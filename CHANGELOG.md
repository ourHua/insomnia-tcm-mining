## [1.0.0] - 2026-05-16

### Added
- Initial public release of the reproducible experiment package.
- Eleven analysis scripts (`step1_data_audit.py` to
  `step11_reproducibility_report.py`).
- Two minimum-necessary input CSVs in `data/`
  (`anonymized_prescription_transactions.csv`,
  `herb_normalization_map.csv`).
- One-command reproduction via `make all`; configurable Bootstrap via
  `make bootstrap1000`.
- Eight figures and six tables auto-generated by the pipeline.
- Manuscript Word document (Version A — most conservative ethics
  framing) in `paper/`.
- Continuous-integration workflow (`.github/workflows/ci.yml`) that runs
  `make all` and asserts that the headline numbers reproduce on every
  push and pull request.
- MIT license for code, CC BY 4.0 license for data, tables, figures
  and manuscript text.

### Verified
- 16 / 16 headline-number assertions PASS in
  `outputs/reproducibility_report.html`.
- Apriori binary rules count: 34 (baseline triple constraint).
- Network: 317 nodes, 11,239 edges, average clustering 0.83,
  diameter 3.
- Community detection: Louvain / Greedy / Leiden all identify 4
  functional modules, modularity Q ≈ 0.04.
- 27-point sensitivity grid: 4 flagship strong pairs persist in
  all 27 parameter combinations.
- Bootstrap robustness (B = 200): Top-10 membership match rate 100 %.
